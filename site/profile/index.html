Profile

ひとりで作っています。
ブラウザゲーム、スマートフォンのアプリ、Web サイト。

作っているもの

Gamesゲーム

あそぶもの。ブラウザで開いたらすぐ始まるものを中心に。導入も登録も要らないこと、それだけは崩さないようにしています。

Appsアプリ

つかうもの。スマートフォンで日常的に使う道具を作ります。機能を足すより、迷わず終わることを優先します。

Sitesサイト

読ませるもの。速く開いて、読みやすく、余計なものが動かない。中身が主役になる作りを心がけています。

作り方

だいたい一人で、手元で動かしながら作っています。設計から絵から音まで通しでやるので、直したいところがあれば、その場で直せます。

釣り合いの調整には、測る手を必ず用意します。ゲームなら自動で何百回も遊ばせて、どこで詰まるかを数字で見る。勘で三回いじって確かめるより、ずっと速くて確かです。

感覚は当たっていた。
でも、原因は思っていたところになかった。

その過程で分かったことは、隠さずNotes に書き残しています。

使っているもの

  • 手書きの HTML / CSS / JavaScript。枠組みは、必要になってから入れます
  • Matter.js — 物理演算（MIT ライセンス）
  • Cloudflare — 配信、Workers、D1
