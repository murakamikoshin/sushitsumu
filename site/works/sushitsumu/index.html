すし積む

シャリから始めて、同じネタ同士をぶつけて育てる落ち物パズル。
行き着く先は、金のすし桶。

どんなゲームか

桶の上からシャリを落とします。同じネタ同士が触れると、ひとつ上のネタに変わる。シャリが玉子に、玉子がエビに、エビがサーモンに——そうやって十一段を上っていきます。

桶からあふれたら、しまい。ただそれだけの遊びですが、大きいネタほど場所を取るので、後先を考えずに積むとすぐ行き詰まります。どこに落とすかを毎回選ぶ、その積み重ねです。

合体で生まれたネタが、間を置かずさらに合体すると「連鎖」。五つ繋がれば「大連鎖」で、点が跳ねます。

入っているもの

寿司図鑑

これまでに作れたネタだけ、姿が見えます。まだのものは影だけ。端末ごとの記録なので、人によって埋まり方が違います。全十二種（ガリを含む）。

番付（オンラインランキング）

その日の上位と、通算の上位。名前を入れて送ると並びます。パソコンで遊ぶと、画面の右に常に出ています。

お品書き

大将が「マグロを二貫」といった注文を出すので、時間内にその通り作るとボーナス。続けて捌くほど倍率が上がり、落とすと一に戻ります。点の出方が普通の遊び方の 1.6 倍ほどになるので、番付は別枠です。

ガリ

二十回に一度くらい、ネタの代わりにガリが来ます。触れたネタをひとつ消します。積み間違えたときの逃げ道です。

遊ぶのに要るもの

ブラウザだけです。導入も、登録も要りません。スマートフォンは指でなぞって位置を決め、離すと落ちます。パソコンは左右キーとスペースでも遊べます。

作りについて

全体が HTML ファイル一枚です。物理演算に Matter.js を使い、寿司の絵は画像ではなく Canvas に毎回描いています。番付は Cloudflare Workers と D1 で動いていて、送られてきた手順を向こうで検算してから並べています。

釣り合いの調整は、自動で遊ばせて数字を取ってから決めました。その話は開発の記録に書いています。
