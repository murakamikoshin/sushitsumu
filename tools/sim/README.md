# 釣り合いを測る道具

配布物（index.html）は一切変えずに、遊びの釣り合いだけを数える仕掛け。
実時間を待たずに早送りできるので、1 戦がおよそ 2 秒で終わる。

    node make-lab.mjs                       # index.html に覗き窓を足した lab.html を作る
    node sim.mjs 100 normal runs.json       # 100 戦まわして書き出す
    node feas.mjs                           # 「そもそも最後まで行けるのか」を組んで確かめる
    node mech.mjs                           # 特定の場面だけを再現して見る

- `vclock.js` … rAF と setTimeout を自前で回す仮想時計。実時間を待たない。
- `bot.js`   … 貪欲な打ち手。合体を最優先し、山が落ち着くまで待ってから置く。
- `lab.html` は作業用の写しで、覗き窓（`window.__dbg`）が付いている。配らない。

`sim.mjs` は `PW=/opt/pw-browsers/...` の chromium を直に叩く。
環境が違うときは `sim.mjs` の executablePath を直すこと。

## 使う前に

    cd tools/sim && npm i playwright-core

`sim.mjs` の `executablePath` は環境の chromium に合わせて直す。

## 最後に測った値（配っている中身、300 戦）

    node make-lab.mjs && node sim.mjs 300 normal runs300.json

| 測ったもの | 値 |
|---|---|
| 点の中央値 | 59,305 |
| 平均 | 60,987 |
| 最高 / 最低 | 163,426 / 25,025 |
| 穴子一本焼きに到達 | 298 / 300（99%） |
| 伊勢海老に到達 | 220 / 300（73%） |
| 金のすし桶に到達 | 31 / 300（10%） |
| 金の桶を一戦で二つ | 0 |
| 1 戦の長さ（中央値） | 7.7 分 |
| 置いた数（中央値） | 589 |
| いちばん長い連鎖 | 10 |

寸法を触ったら、ここをもう一度まわして書き換えること。
サイト側（koshin-studio の `data/works.json` の `stats`、`notes/anago/`）が
この値を載せている。

### 番付の当たり方（別の 120 戦）

打ち手（bot）の点を、いまの `RANK_SCORE` に当てはめると:

| 段 | しきい値 | 当たり |
|---|---|---|
| 見習い職人 | 0 | 0% |
| 追い回し | 12,000 | 0% |
| 若手職人 | 26,000 | 6% |
| 中堅職人 | 42,000 | 32% |
| 花板 | 58,000 | 40% |
| 大将 | 72,000 | 14% |
| 伝説のすし職人 | 85,000 | 8% |

bot は人より上手いので、下二段に落ちない。
人が遊ぶぶんには下二段が効いてくる、という前提の並び。
